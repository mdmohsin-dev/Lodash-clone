# Lodash Clone

A JavaScript utility library inspired by Lodash, built from scratch for learning and understanding how core utility functions work internally.

---

## 📌 About

This project recreates commonly used utility functions step by step, focusing on:
- Understanding internal logic  
- Writing clean and reusable code  
- Improving problem-solving skills  

---

## 🧪 Example Usage

```js
import _ from "./index.js";

const chunks = _.chunk([1, 2, 3, 4, 5], 2);
console.log(chunks);

output
[[1, 2], [3, 4], [5]]
