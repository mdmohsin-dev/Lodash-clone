# slice

Creates a shallow copy of a portion of an array into a new array.

## Parameters

- `array` (Array): The array to slice  
- `start` (number): The start index (inclusive)  
- `end` (number): The end index (exclusive)  

## Returns

- (Array): Returns the new sliced array

## Example

```js
slice([1, 2, 3, 4], 1, 3);

outpu
[2, 3]
