# lte

Checks if one value is less than or equal to another.

## Parameters

- `a` (*): The value to compare  
- `b` (*): The other value to compare  

## Returns

- (boolean): Returns `true` if `a` is less than or equal to `b`, else `false`

## Example

```js
lte(3, 5);  => true
lte(4, 4);  => true
lte(7, 2);  => false
