# subtract()

Subtracts one number from another.

## Parameters

- `minuend` (number): The number to subtract from  
- `subtrahend` (number): The number to subtract  

## Returns

- (number): Returns the result of subtraction  

## Example

```js
subtract(10, 4); => 6

subtract(5, 10); => -5

subtract(7, 0); => 7
