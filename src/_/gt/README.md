# gt

Checks if one value is greater than another.

## Parameters

- `a` (*): The value to compare  
- `b` (*): The other value to compare  

## Returns

- (boolean): Returns `true` if `a` is greater than `b`, else `false`

## Example

```js
gt(5, 3);    => true
gt(2, 4);    =>false
gt(10, 10);  =>false
