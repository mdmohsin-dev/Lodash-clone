# min

Finds the smallest number in an array.

## Parameters

- `array` (Array): The array of numbers to inspect  

## Returns

- (number | undefined): Returns the smallest number, or `undefined` if the array is empty  

## Example

```js
min([4, 2, 8, 1]); => 1

min([10, 5, 7]); => 5

min([]); => undefined
