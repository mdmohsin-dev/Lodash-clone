# chunk()

## 📌 Description
`chunk` function splits an array into smaller sub-arrays based on a given size.

---

## ⚙️ Parameters

- `array` (Array): The array to split  
- `size` (Number): Number of elements per chunk  

---

## 📤 Returns

- A new array of sub-arrays (chunks)

---

## 🧪 Example

```js
chunk([1, 2, 3, 4, 5], 2);

```output
 [[1, 2], [3, 4], [5]]
