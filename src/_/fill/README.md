# fill()

Fills elements of an array with a given value from a start index to an end index.

## Parameters
- `array` (Array): The array to modify  
- `value` (any): The value to fill with  
- `start` (Number): Start index (default: 0)  
- `end` (Number): End index (default: array.length)

## Example
```js
fill([1, 2, 3, 4], 'a')

output
['a','a','a','a']
