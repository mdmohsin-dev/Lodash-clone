# gte

Checks if one value is greater than or equal to another.

## Parameters

- `a` (*): The value to compare  
- `b` (*): The other value to compare  

## Returns

- (boolean): Returns `true` if `a` is greater than or equal to `b`, else `false`

## Example

```js
gte(5, 3);  => true
gte(4, 4);  => true
gte(2, 6);  => false
