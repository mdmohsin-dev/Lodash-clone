# pullAll

Removes all given values from an array using an array of values.

## Parameters

- `array` (Array): The array to modify  
- `values` (Array): The values to remove from the array  

## Returns

- (Array): Returns the modified array

## Example

```js
pullAll([1, 2, 3, 4, 5, 6], [1, 3]);

output
[2,4,5,6]
