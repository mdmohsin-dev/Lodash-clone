# divide

Divides one number by another and returns the result.

## Parameters

- `dividend` (number): The number to be divided  
- `divisor` (number): The number to divide by  

## Returns

- (number): Returns the division result  

## Example

```js
divide(10, 2); => 5

divide(7, 2); => 3.5

divide(5, 0); => Infinity
