# repeat

Repeats the given string `n` times and returns the result.

## Parameters

- `string` (string): The string to repeat  
- `n` (number): The number of times to repeat the string  

## Returns

- (string): Returns the repeated string  

## Example

```js
repeat('*', 3); => '***'

repeat('abc', 2); => 'abcabc'

repeat('a', 0);  => ''
