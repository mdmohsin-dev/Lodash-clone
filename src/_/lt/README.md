# lt

Checks if one value is less than another.

## Parameters

- `a` (*): The value to compare  
- `b` (*): The other value to compare  

## Returns

- (boolean): Returns `true` if `a` is less than `b`, else `false`

## Example

```js
lt(3, 5);    => true
lt(4, 2);    => false
lt(10, 10);  => false
